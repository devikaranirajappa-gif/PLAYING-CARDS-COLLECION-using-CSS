# 🃏 Playing Cards Collection

A beginner-friendly web project built using HTML5 and CSS3 that recreates a collection of classic playing cards. This project demonstrates essential front-end development skills, including CSS styling, positioning, borders, images, and hover effects.

** ✨ Features

- 🂡 Number Cards
- 👑 Face Cards (Jack & Joker)
- 🎴 Card Back Designs
- ✨ Hover Effects
- 🎨 Custom CSS Styling
- 📐 Clean Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
** 📖 What I Learned

- HTML Structure
- CSS Selectors
- Positioning
- Borders & Spacing
- Background Images
- Hover Effects
- Card Layout Design

## 🚀 Future Improvements

- Add more playing cards
- Improve card animations
- Use CSS Grid and Flexbox
